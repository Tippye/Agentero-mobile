# 平板阅读路由恢复

移动壳按当前原生窗口标签与 Vault 命名空间保存路由：论文 ID、文献库/广场/Agent 页签、PDF/笔记模式、工作区预设、PDF 页码与缩放。它只保存阅读导航，不保存笔记正文、提示词、账号或 Host 信息。库载入后才把论文 ID 解析为当前 metadata；已删除的论文回到文献库，未下载的原件继续沿用既有按需获取路径。

## 持久化与并发

[原生存储](../../../src-tauri/src/features/mobile_route/mod.rs)位于应用私有数据目录的 `mobile-routes`。IPC 注入调用方 `WebviewWindow`，不接受 JS 指定另一个窗口标签。Vault 字符串只参与长度分帧的 SHA-256 命名空间计算，不能成为读写任意路径的授权。

读取返回规范十进制版本号与可选路由；首次为空版本 `0`。保存必须携带读取后的当前版本，使用既有文件变更锁、0600 原子替换、文件同步及 Unix 目录同步。两个存储实例竞争相同版本只允许一个成功。非法数值、溢出、符号链接、损坏或超限文件均报错，不覆盖原数据；该 CAS 协调同一 Rust 进程的调用，不承诺与外部编辑进程互斥。

[前端协调器](../../../src/components/mobile/hooks/use-mobile-route.ts)先完成只读载入并等待论文库，再统一恢复。用户已经选择论文、改变模式或导航时，迟到的读取不覆盖当前意图。写入静置 400ms、严格单请求在途并合并最新路由，收到新版本才继续下一次保存；后台与 pagehide 尝试立即提交。损坏、CAS 冲突和其他写入错误只提示一次并停止该协调器，不自动重试覆盖。系统直接终止进程时，最多恢复到最后一次已确认保存；不依赖关闭事件作为唯一保存机会。

恢复含论文的路由时默认进入阅读页，并关闭对照/研讨面板。保存的预设不意味着允许自动展开右侧栏；新开论文与从 Agent 返回遵循相同规则，手动选择预设与明确圈选提问仍可展开。广场拥有单独页签，不在后台加载前启动其页面请求。

## PDF 恢复

[阅读快照](../../../src/lib/pdf/reading-position.ts)复用现有 EmbedPDF 布局就绪、缩放和页码恢复流程。每个稳定文档身份只初始化一次；同一论文缓冲区重载优先使用已有精确物理锚点。观察到实际恢复页码与缩放之前，不回传默认的第一页/默认缩放覆盖已保存状态。回调携带捕获的文档身份，父层拒绝旧论文的迟到回调；原件字节也绑定论文、路径和 Vault，不能短暂作为另一篇论文渲染。

## 验证

5 项原生存储回归通过，覆盖跨实例/重建读取、窗口与 Vault 隔离、并发 CAS、损坏保留、数值边界、版本耗尽与符号链接拒绝。生成及只读绑定、9 项事件契约、全工作区严格 Clippy、全量 TypeScript、1465 模块/8003 条依赖检查通过。11 个相关前端文件的 91 项联合回归包含 14 项实际 React 路由协调器、PDF 初始化/布局顺序、旧文档回调与待载原件隔离，以及既有工作区和圈选提问流程。

隔离 macOS Tauri 宿主实际运行生成 IPC 验证写入/读回与陈旧 CAS 拒绝；真实 WebView 挂载实际协调器，从原生存储恢复模式、页码与缩放，再将用户导航经串行队列写回原生存储并读回确认。仅使用私有测试命名空间，没有操作真实 Vault 或 Host。该流程不代表 PDF 前台像素绘制、Android/iOS 系统回收或独立原生窗口验收。

## 原生多窗口边界

此项提供按窗口保存与恢复导航的基础，不宣称当前已实现独立 Android Activity 或 iOS Scene。移动 capability 已包含 `doc-*`，但桌面文档根与新窗口命令仍保持桌面 gate。

已核对仓库固定版本 Tauri 2.12.5、Tao 0.37.2 和 Wry 0.57.1：Android 的公开 `activity_name` 构建选项需要合适且独立声明的 Activity。当前默认构建可能复用主 Activity 并替换它的 WebView；主 Activity 的 `singleTask` 也不能直接作为第二个文档 Activity，SDK 的 Android focus 方法尚无实现。iOS 只有 `supportsMultipleScenes` 时才请求新 Scene，当前平台尚无多场景声明；激活失败是异步反馈，当前也未处理系统的 `SceneRequested` 恢复入口。

原生适配还须建立稳定路由与 Activity/Scene 会话的映射、打开中的原子预留、针对已有窗口的真实激活确认、回收恢复和内存上限。SDK 窗口注册表标签与 builder 返回成功均不足以证明产生或聚焦独立的系统窗口。在设备闭环完成前不开放“在新窗口打开”入口。
