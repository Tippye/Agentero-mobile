# 平板圈选区域提问

阅读器的套索工具可以在没有任何笔迹的 PDF 图表、公式或文字区域上圈选，然后点“就此区域提问”。截取的是未旋转可见 CropBox 的归一化区域，复用现有 PDFium 源 PDF 裁剪；源 PDF、手写 sidecar 和高亮记录保持不变。截图不包含独立压力笔迹层，不会创建空白 visual mark。套索移动或复制笔迹后刷新所选区域，避免提问旧位置。

## 从阅读器到草稿

[PdfViewer](../../../src/components/viewer/pdf/pdf-viewer.tsx) 的可选 `onRegionPrompt` 回调只返回一基页码、归一化矩形和 PNG。截图期间共享忙状态，重复点击不发起多次裁剪；文档 ID、engine、文档对象或组件寿命发生变化时，迟到的结果丢弃。大尺寸页面也遵守最长边 1600 像素的输出上限。

[MobileReaderPage](../../../src/components/mobile/mobile-reader-page.tsx) 在捕获完成时复制论文 ID、标题、页码、矩形与截图，生成独立来源 UUID。[MobileApp](../../../src/components/mobile/mobile-app.tsx) 复核当前 Vault、论文、provider、保存与弹窗状态，只保留一个待发送参考，不替换已有参考。宽窗口切到保留 PDF 的研讨布局，窄窗口转到 Agent 页；原有问题、附件与会话状态继续保留。默认远程 provider 提供这一入口；旧 Bridge 页尚未接入图像附件，因此不显示回调入口。

接收草稿本身不上传、不发送，也不自动选择远端主机或新建会话。用户可以预览、移除参考，选择是否附上截图，然后显式发送。当前通道不支持截图上传或 MIME 限制不兼容时，需要明确取消“附上区域截图”，才能仅发送标题、页码、矩形与来源 ID；界面不会悄悄丢弃图像。

## 私有暂存与发送

[paper-context.ts](../../../src/lib/mobile/paper-context.ts) 只接受受限 PNG envelope，检查 base64、签名、IHDR 与 1600 像素尺寸上限；按主机限制与本地 12 MiB 两者的较小值检查字节数。它不是通用图片解码器，生产输入来自上述有界 PDFium 裁剪。元数据与图片在进入 shell 前复制，后续切换论文不会改写旧参考的标题或矩形。

只有用户点发送，才在应用私有缓存 `remote-region-drafts` 中用随机 UUID basename 和 `createNew` 独占创建临时 PNG。论文标题和本地 ID 不参与文件路径。暂存与清理均拒绝符号链接目录；清理只操作自己生成的非链接普通文件，不递归删除。不能确认的写入保留唯一缓存项，不按异常盲目移除可能已存在的文件。正常上传完成或失败返回后清理临时项；清理失败 Toast 提示。

[RegionContextWorkflow](../../../src/lib/remote-agent/region-context-workflow.ts) 复用现有原生私有文件上传与 [OperationJournal](../../../src/lib/remote-agent/model.ts)。上传和发送各自持有操作 ID：

- 上传成功后仅使用回执中匹配原会话的附件；发送被确定拒绝时重用该附件，后续显式重试不重复上传。
- 上传或发送结果未知时保留参考和原操作 ID。查询回执只更新结果，不能自动继续上传或发送；普通“允许新操作”也不能重放这一参考的未知操作。
- 每个 await 后检查原 session、connection、context 与组件寿命。用户中途换会话时，不向新会话注入旧附件，不把迟到的确认当成新会话的发送结果。
- 已确认发送的来源在当前视图内按目标保存有界 metadata 映射，不保留图像或本地绝对路径；重复处理同一确认不会覆盖后续输入的新问题。

提示词把来源 UUID、论文标题与归一化矩形编码成引用数据，并标为参考资料；论文的本地绝对路径不进入提示词。DSH 附件走已有原生 workspace 文件引用，而非假定远程存在相同 Vault 路径。原生 journal 继续只保存摘要、操作目标与结果，不保存截图、提示词或临时路径，见[远程状态恢复](remote-agent.md)。来源映射与未发送截图仍属于当前 WebView 内存，重启不恢复草稿，但原生未知操作仍阻止自动重发。

## 验证

有意义的回归覆盖：无笔迹区域的套索、裁剪/旋转坐标、超大页面上限、重复裁剪和文档替换、草稿及来源保留、超限/MIME/链接路径拒绝、明确发送、未知结果、回执、已上传附件复用与切换会话。隔离的 macOS Tauri 宿主已实际运行私有缓存创建、PNG 写入/读取、幂等清理与协商字节上限拒绝。在同一真实 WebView 中，使用完全隔离的模拟 provider 与实际原生文件插件，还通过了截图放大查看→输入问题→连续两次点发送→一次上传/一次发送→来源绑定/不同操作 ID→确认后清空和移除临时文件的 DOM 流程；接收参考和预览均未调用模拟写操作。此流程未联系真实远程 Host，也不代表前台像素绘制通过。设备触笔、前台视觉与真实 Host 接收和回跳仍需设备验收。
