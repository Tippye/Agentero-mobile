# 移动端

Agentero 移动端是本地优先的平板/手机阅读应用：论文、笔记和批注直接保存在设备上的知识库（Vault）里，离线也能阅读和书写。通过对象存储或 WebDAV 同步，可以在电脑和移动设备之间共享同一个知识库；Agent 对话连接远程 DSH 主机，不在设备上运行本机 Agent。

## 安装与首次启动

Android 用户可在发布页下载适用于 ARM64 的 APK；iPhone 和 iPad 需要可用的 iOS 构建。首次启动会在应用私有目录创建本地知识库，不需要先配对电脑。

- 文献库、广场与 Agent 在左侧导航切换；宽屏平板可同时显示论文列表和阅读器。
- Android 的配置、缓存和数据根由原生侧指定，不依赖 `HOME`；iOS 使用系统 Library 目录。

## 导入论文

- **魔棒入库**：粘贴 DOI、arXiv 标识或标题，确认候选后入库。解析、下载和编目由原生任务执行，关闭弹窗后任务仍继续；完成前不会提前标记成功。
- **订阅与推荐**：广场提供订阅源、arXiv 推荐和 Hugging Face Daily Papers。入库操作先打开魔棒供确认。
- **本地 PDF**：通过系统文件选择器导入 PDF，文件经应用私有暂存目录进入知识库。Android 支持从其它应用「打开方式」接收 PDF；iOS 支持 Inbox 拷贝。

## 阅读与手写

阅读器使用本地 PDF，按屏幕宽度自动切换单栏阅读、双栏对照和研讨布局。

- **手指**平移页面，**双指**缩放；笔接触纸面即进入书写，不会误触发滚动。
- 手写工具栏提供笔、荧光笔、按笔擦除、套索移动/复制/删除、撤销和重做。笔未抬起停留片刻会把当前笔迹吸附为规范图形（直线、箭头、矩形、三角形、圆/椭圆）。
- iOS Pencil 双击遵循系统偏好；标准笔侧键与反转橡皮擦可用。
- 批注和笔迹保存在论文目录的 `marks/` 下，桌面端能显示同格式笔迹。
- 导出会生成带笔迹的 PDF 副本，不改原件；保存走系统原生对话框。

移动端不提供 PDF 文本划选；圈选提问请使用手写工具栏的套索区域框选。

## 翻译与版面解析

- 阅读页可手动触发全文翻译和版面解析，任务由原生 JobCenter 执行，离开当前论文不会取消。
- 翻译只补缺失块，可显式重新翻译；已完成块和外部解析任务回执在重启后可复用。
- 排版重建（reflow）字体优先从镜像下载；离线时使用内置保底字体，保证译文 PDF 仍能生成。
- 锁屏期间批量翻译通过原生后台传输租约继续；iOS 为实际同步/传输登记有限后台窗口。

## 同步知识库

进入 **设置 → 同步**，选择对象存储（S3 兼容）或 WebDAV 作为主同步源，填写地址和凭据后连接。主同步源负责设备间的双向同步。

连接主同步源后，可以添加 S3 或 WebDAV 只读镜像。镜像接收此设备发布的知识库副本，镜像上的改动不会回传到本机或主同步源。镜像发布需要先下载同步范围内的文件，可将下载策略设为**完整下载**后再同步。

- 笔记、元数据、高亮和嵌入图片始终同步；PDF、LaTeX 源码、附件、手写笔迹和译文 PDF 按范围开关选择。
- **下载策略**支持按需下载：论文列表先同步元数据，打开论文时才拉取 PDF；也可把常用论文固定为离线可用。
- 文献库论文行左滑可固定（离线保留）或删除（移入回收站，需二次确认）。
- 两台设备分别修改了同一文件时，应用会暂停本轮同步并弹出冲突列表。逐文件选择**保留本地**、**保留云端**或**两份都保留**。默认保留两份，选中的版本留在原路径，另一份保存为冲突副本。
- 选择**稍后**可继续使用应用。打开 **设置 → 同步**可以再处理，重启后也会提示。笔迹和批注仍按记录合并。
- 主同步源使用 WebDAV 时，如果服务器缺少条件写支持，可以在设置中启用降级同步。移动端仍会在双向改动冲突时请求逐文件确认。
- 自动同步在前台运行：回到前台、静默一段时间后和按间隔触发。

## Agent 对话

Agent 页默认连接 DSH 远程主机：登录后选择工作区和会话，即可发消息、看流式回复、回答权限审批和结构化提问。设备身份、令牌和主机指纹保存在系统凭据存储（Android Keystore / iOS Keychain）。

- 套索圈选 PDF 区域后可发起「区域提问」：预览截图和引用，确认发送后才上传。
- 与电脑端 Bridge 配对仍保留为显式可选入口，用于连接在线桌面端。
- 移动端不运行本机 CLI Agent、SSH 知识库、Word/TeX 集成或桌面服务。

## 系统交互

- Android 系统返回键先关闭弹窗和侧栏，再回阅读预设或文献库；笔记或笔迹未保存时有退出保护。
- 内容自动避让系统栏、刘海与键盘（Android 原生帧避让，iOS 安全区域）。
- 后台运行分区按设备实际能力展示；通知授权和电池优化设置均需用户明确操作。

工程契约与平台适配细节见仓库 `docs/development/mobile/`。
